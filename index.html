TTL PTOSM Agent

Aplikasi internal pribadi untuk memindahkan dokumen operasional (Daily Report, Statement of Fact, Outturn Report) dari sistem PTOS-M ke folder TTL-PTOSM di Google Drive milik pemilik aplikasi sendiri.

  • Hanya dipakai oleh pemiliknya; tidak untuk pengguna umum.
  • Izin Google yang diminta: drive.file — hanya file yang dibuat oleh aplikasi ini.
  • Tidak membaca, mengubah, atau menghapus file lain di Google Drive.
