TTL WA Perform

Aplikasi internal pribadi untuk menyimpan file rekap kinerja bongkar (Excel) ke folder ttl-agent di Google Drive milik pemilik aplikasi sendiri, setiap jam.

  • Hanya dipakai oleh pemiliknya; tidak untuk pengguna umum.
  • Izin Google yang diminta: drive.file — hanya file yang dibuat oleh aplikasi ini.
  • Tidak membaca, mengubah, atau menghapus file lain di Google Drive.

Kebijakan privasi: waprivasi.html
