Kebijakan Privasi — TTL WA Perform

Berlaku sejak 23 Oktober 2026.

Siapa pengguna aplikasi ini

Aplikasi ini hanya dipakai oleh pemiliknya untuk keperluan kerja sendiri. Tidak ada pendaftaran pengguna umum.

Data Google yang diakses

Aplikasi meminta izin https://www.googleapis.com/auth/drive.file: hanya dapat melihat dan mengubah file yang dibuat oleh aplikasi ini di Google Drive pemilik (folder ttl-agent). Aplikasi tidak dapat membaca file lain.

Penggunaan data

  • File rekap diunggah ke Google Drive pemilik sendiri untuk dibaca oleh sistem laporan internal pemilik.
  • Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan.
  • Token akses disimpan di server kerja pemilik dengan izin baca terbatas, dan dapat dicabut kapan saja melalui pengaturan Akun Google (Keamanan → Aplikasi pihak ketiga).

Kontak
